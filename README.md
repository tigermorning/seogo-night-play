# 서고의 밤 (Night in the Archive)

브라우저에서 바로 하는 추리 게임. 설치도 로그인도 없다.

**▶ https://tigermorning.github.io/seogo-night-play/**

어젯밤 21시부터 새벽 2시 사이, 성의 서고에서 기밀 문서가 사라졌다. 성문은 닫혀
있었고 그 시각 성 안에는 다섯 사람뿐이었다 — 경비병 카일, 시녀 미라, 상인 도른,
요리사 하웰, 마부 벤. 그중 하나가 첩자다.

당신은 아침에 도착한 심문관이다. 해가 질 때까지 **열여덟 번** 말을 걸 수 있고,
마지막에 **단 한 번** 지목한다. 이기려면 **첩자 · 그가 거짓말한 시각 · 그것을
증명하는 목격자** 셋을 한꺼번에 맞혀야 한다.

자유롭게 타이핑해서 물으면 된다. 정해진 선택지는 없다.

## 심문 요령

다섯이 서로 다르게 반응한다. 같은 방식으로는 다섯을 다 열 수 없다.

| | |
|---|---|
| **카일** | 정중히 물어라. 몰아붙이면 그 자리에서 입을 닫는다 |
| **미라** | 다독여라. 다그치면 아무것도 안 나온다 |
| **도른** | 압박은 안 통한다. 다른 사람의 증언을 모아 와서 들이대라 |
| **하웰** | 한 번에 한 가지씩, 정확하게. 그의 시각 기억은 흐려지지 않는다 |
| **벤** | 마음껏 물어라. 대신 **직접 봤는지 들었는지**를 캐물어라 |

> **목격은 같은 방에서만 가능하다.** 이 한 줄이 게임 전체를 지탱한다.
> 안 가 본 방에 대해서는 「비어 있었다」고 말할 수 없고 「모른다」고 해야 한다.

## AI 대화로 돌리기 (선택)

**아무것도 안 해도 게임은 완전히 돈다.** 모델 없이도 다섯 인물이 성격대로 답한다.

큰 모델을 붙이면 **말을 알아듣는 폭이 넓어진다** — 에두른 물음, 생략된 말,
평서문으로 된 요구까지 받는다. 켜는 법:

1. 오른쪽 위 **AI** 단추
2. 공급자와 값을 넣는다

| 공급자 | 넣을 것 |
|---|---|
| **OpenAI 호환** (순순 SAM) | 엔드포인트 `https://sam.soonsoon.ai/openai/v1` · 모델 `claude-haiku` 또는 `claude-sonnet-5` · 자기 키 |
| **Claude** | 모델 `claude-sonnet-5` 또는 `claude-haiku-4-5` · 자기 키 |

**키는 각자 자기 브라우저에만 저장된다**(`localStorage`). 서로 공유되지 않으니
각자 자기 키를 넣어야 한다. 공용 컴퓨터에서는 넣지 마라.

**로컬 올라마는 이 링크에서 안 된다** — 브라우저가 자기 PC의 `localhost:11434`를
찾기 때문이다. 쓰려면 HTML 파일을 내려받아 직접 열어야 한다. 그리고 7B 급으로는
대사 품질이 오히려 떨어진다(실측). 붙일 거면 큰 모델을 붙여라.

## 사실은 엔진이 쥔다

모델을 바꿔도 **정답·행적·목격·기억은 바뀌지 않는다.** 모델은 말을 알아듣고
말을 고르는 데만 쓰인다. 추리에 쓰이는 사실은 지어낼 수 없다.

단일 자족 HTML 한 장. 바깥에서 받아오는 것은 없다(AI를 켰을 때의 모델 호출만
예외). 소스와 시험 도구는 비공개 저장소에 있다.
